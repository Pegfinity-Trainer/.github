> [!IMPORTANT]
> Pegfinity is a single-player puzzle game. All options are **client-side only** — no host guard needed.

## What it does

Pegfinity is a meditative puzzle game where you clear pegboards with satisfying physics-based shots. Each level has a par score and limited moves — perfection is the goal.

This trainer removes the limits. **Unlimited moves** lets you experiment freely, **instant clearing** solves boards in one click, and **max score** guarantees 3-stars every time. **Unlock all levels and themes** gives you full access to the game's content.

## Features

## Hotkeys

`Insert` opens the menu · `End` resets everything · `F1`–`F11` as above, all rebindable
